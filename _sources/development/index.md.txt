# Development

Contributions welcome. Everything is discussed via GitHub Issues; if
you're working on something, comment on the issue so we can assign it.

To add a **hardware tool** — the most common contribution — see
[Design a new tool](../new_tool/index.md) instead. This section covers
core code contributions and the shorter labware / deck / digital-twin
plugin types.
