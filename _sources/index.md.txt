# Science Jubilee

`science-jubilee` is a Python interface to a
[Jubilee](https://jubilee3d.com/index.php?title=Main_Page) multi-tool motion
platform, used for laboratory automation.

The documentation is organised in six sections:

- **Getting Started** — install, first session, `.env` files.
- **User Guides** — patterns for writing experiments, full environment-variable reference, troubleshooting.
- **Build Guides** — physical assembly of the motion platform and existing tools.
- **Design a New Tool** — hardware + plugin instructions to add a brand-new tool.
- **Development** — how to contribute, and how to package labware / deck / twin plugins.
- **Reference** — entry-point table, machine-state resolver, trace format.
